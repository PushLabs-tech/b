# Builder — Grand Finale frontend

This frontend is deliberately styled around the interaction model visible in modern AI app builders: a simple left navigation, large central intention composer, project workspace, AI conversation, live preview, file surface and utility tabs.

Your differentiation is the universal intention engine:
Understand → Classify → Plan → Build → Connect → Execute → Measure → Adapt.

Included locally: Home, Projects, Templates, Activity, Research, Integrations, Agents, Settings, new project flow, Build/Discuss/Plan/Visual Edit/Research modes, chat, preview, files, data, workflows, tests, security, versions, publish, search, command palette, mobile navigation, local persistence and project export.

Not faked: real Gemini, Supabase, GitHub, Cloudflare, external research, secure secrets, real browser automation or real deployment. Those need the backend phase.
